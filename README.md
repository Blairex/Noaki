My personal dotfiles for Linux. I run Arch with Hyprland, and this repo is where I track all my customizing.

This is a work in progress. I'm still building things out, changing stuff, and breaking it, so nothing here is finished or final. Configs get added as I go, and what's in the repo today is not everything it will have later.

Right now it covers my window manager and launcher setup, and more will be added over time, like the bar, the terminal, and other tools. I also have a theme system in the works that switches the wallpaper and colors across everything at once. The theme I'm using at the moment is graphite-mono, a black and white monochrome look.

Wallpapers are not included in the repo.

This is just my own setup, kept here for tracking. It's not made as a ready-to-use config for anyone else, but feel free to look around and take ideas.
